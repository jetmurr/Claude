# 01 · Vision & Ziele

## Das Problem

Geschäftsideen werden heute oft **bauchgesteuert** bewertet: Man hört von einer
Chance (z. B. „QNG-Zertifizierungen boomen"), recherchiert ein paar Stunden,
und entscheidet aus dem Gefühl heraus. Drei wiederkehrende Schwächen:

1. **Die Idee ist nie sauber definiert.** Es wird über „QNG machen" geredet,
   ohne zu klären: Plattform? Eigener Auditor? Software? Beratung? Jede Variante
   ist ein anderes Geschäft mit anderem Risiko.
2. **Die Recherche ist unbelegt.** Zahlen stammen aus dem Bauch, aus einem
   einzelnen Blogpost oder aus einem LLM — und sind damit als
   Entscheidungsgrundlage wertlos.
3. **Es gibt keinen Übergang von Idee zu Umsetzung.** Die Analyse endet mit
   einem PDF, das niemand in einen Plan übersetzt.

## Die Vision

**Venture Lens** ist ein System, das eine Geschäftsidee von der ersten
Eingebung bis zur fundierten Umsetzungsentscheidung begleitet — strukturiert,
belegt und wiederholbar. Es macht drei Dinge gut:

- **Aufbereiten:** Jede Idee wird zuerst so klar formuliert, dass ein
  Außenstehender sie versteht — inklusive sauber getrennter Geschäftsmodell-
  Varianten und ihrer Vor-/Nachteile.
- **Durchleuchten:** Markt, Wettbewerb, Nachfrage, Regulatorik, Wirtschaftlich­keit
  und operative Machbarkeit werden nach festem Raster geprüft — jede Aussage mit
  Quelle und Qualitätsstufe.
- **Entscheiden & überführen:** Aus der Analyse entsteht eine **Go/No-Go-
  Empfehlung** und — bei Go — direkt ein Umsetzungsplan.

## Was die Software konkret leistet

| Fähigkeit | Beschreibung |
|---|---|
| **Ideenfindung** | Rohideen erfassen, in Varianten/Geschäftsmodelle auffächern, vergleichbar machen |
| **Idee verständlich machen** | Laienverständliche Aufbereitung + Vor-/Nachteile je Variante (Pflicht-Phase 1) |
| **Informationsfindung** | Strukturierte Recherche mit definierten Quellen und Evidenz-Bewertung |
| **Sachlagenfindung** | Markt, Wettbewerb, Regulatorik, Nachfrage als Faktenbasis erheben |
| **Wirtschaftlichkeitsprüfung** | Unit Economics, Szenarien, Break-even — jetziger Stand *und* Zukunftsaussicht |
| **Entscheidung** | Scoring → Go/No-Go mit nachvollziehbarer Begründung |
| **Umsetzung** | Roadmap, kritischer Pfad, CAPEX/OPEX, Risiken — der Sprung in die Realität |

## Zwei Betriebsmodi

Die Software trennt sauber zwei Modi, die oft vermischt werden:

1. **Validierungs-Modus** (Should we do it?) — Analyse bis zur Entscheidung.
   Das ist der QNG-Pilot.
2. **Umsetzungs-Modus** (How do we do it?) — Planung & Steuerung der Realisierung.
   Beginnt erst nach einem „Go".

> Der QNG-Anwendungsfall in diesem Repo läuft im **Validierungs-Modus** mit einem
> *Ausblick* auf die Umsetzung (Phase 6). Die tatsächliche Umsetzung ist
> Folgeprojekt.

## Was die Software *nicht* ist

- **Kein Wikipedia-Generator.** Output ist eine Entscheidung, kein Lexikonartikel.
- **Kein Bauchgefühl-Verstärker.** Ohne belegte Daten gibt es kein „Go".
- **Kein Ersatz für Primärrecherche.** Sie *erzwingt* sie (Mystery Shopping,
  Interviews), statt sie zu ersetzen.
- **Kein Ideenfriedhof.** Verworfene Ideen werden mit Begründung archiviert und
  bleiben reaktivierbar, wenn sich Rahmenbedingungen ändern.

## Erfolgskriterien der Software (nicht des Einzelprojekts)

1. Zwei beliebige Personen kommen mit demselben Datenstand zur **gleichen
   Go/No-Go-Logik** (Nachvollziehbarkeit).
2. Jede Kennzahl im Output ist **bis zur Quelle rückverfolgbar**.
3. Eine neue Idee lässt sich in **< 1 Tag** in einen strukturierten
   Analyse-Plan überführen (Wiederverwendbarkeit der Templates).
4. Aus einem „Go" entsteht **ohne Medienbruch** ein Umsetzungs-Backlog.
